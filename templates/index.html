Step-by-Step Guide • 1. Bulk DNS Manager

Purpose: Add, replace, or delete single or multiple specified DNS records across unlimited Cloudflare domains in parallel, with optional SSL mode updates.

  1. Step 1 — Cloudflare Token: Choose a saved Cloudflare account above or paste a User API Token with Zone:Read, DNS:Edit, and Zone Settings:Edit.
  2. Step 2 — Domain List (Unlimited): Paste one domain or subdomain per line. Click Clean & Deduplicate to remove https://, paths, and duplicates.
  3. Step 3 — Action & Record Details: Pick Replace / Create, Add If Missing, Delete Record, or Delete Specified DNS Records (adds multiple Type + Host + optional Content rules in one run).
  4. Step 4 — Confirmation & Safety: Deleting records triggers a confirmation prompt before running and only removes matching specified records without affecting other DNS records.
  5. Step 5 — Execute & Follow Up: Click Execute Bulk DNS (or Ctrl + Enter). Filter Failed rows if needed, click Retry Failed, and click Export Tab CSV.
Unlimited rows / run
Download Sample CSV

Columns: domain, action (replace/add_if_missing/merge_spf/delete), type, name, content, proxied, priority, ttl, ssl_mode

Smart SPF Merge: Any row with type=SPF, action=merge_spf, or TXT containing v=spf1 automatically merges into an existing SPF record (or creates a new one if none exists).

Step-by-Step Guide • 2. CSV Multi-Record Import

Purpose: Apply multiple DNS record types (A, CNAME, MX, TXT, SPF) or domain-specific values in one unlimited batch.

  1. Step 1 — Download Sample CSV: Click Download Sample CSV to inspect the exact column headers and sample values.
  2. Step 2 — Populate Rows (Unlimited): Enter domain, action (replace, add_if_missing, merge_spf, or delete), type, name, and content.
  3. Step 3 — Smart SPF & Optional SSL: SPF records merge seamlessly with existing v=spf1 records. Leave ssl_mode blank unless you want to patch SSL on that domain.
  4. Step 4 — Upload & Run: Select your .csv file, ensure your Cloudflare token is set above, and click Upload & Run CSV.

Step-by-Step Guide • 3. SSL & Cache Purge

Purpose: Standardize TLS/SSL modes, enforce HTTPS redirects, fix mixed-content links, and purge cached edge files across unlimited zones.

  1. Step 1 — Cloudflare Token: Ensure your token has Zone Settings:Edit and Cache Purge:Purge permissions.
  2. Step 2 — Paste Domains (Unlimited): Enter one root domain per line in the left box.
  3. Step 3 — Choose SSL/HTTPS Options: Select Flexible (for HTTP origins like S3 static websites) or Full (Strict) (for SSL origins), plus Always Use HTTPS = On.
  4. Step 4 — Optional Cache Purge & Run: Check Purge Everything if deploying fresh site changes, then click Apply SSL & Cache Settings.

Step-by-Step Guide • 4. Bulk Redirects

Purpose: Deploy 301/302 forwarding Page Rules across unlimited domains to redirect root traffic to www or an external destination URL.

  1. Step 1 — Cloudflare Token: Ensure your token has Page Rules:Edit and DNS:Edit permissions.
  2. Step 2 — Paste Domains (Unlimited): Enter one root domain per line in the left box.
  3. Step 3 — Choose Redirect Mode: Select Root → Subdomain (e.g. www) or Forward Entire Domain → Custom Target URL (supports {domain} placeholder).
  4. Step 4 — Proxied Origin & Execute: Keep Auto-create proxied root A record checked so Cloudflare's proxy intercepts requests, then click Create Bulk Redirects.

Step-by-Step Guide • 5. Add Zones & Fetch NS

Purpose: Bulk-add unlimited new root domains into a chosen Cloudflare account or retrieve assigned Cloudflare nameservers for registrar updates.

  1. Step 1 — Cloudflare Token: Ensure your token has Account Settings:Read and Zone:Edit permissions.
  2. Step 2 — Load Target Account: Click Load Accounts on the right and pick the Cloudflare account where new zones should be created.
  3. Step 3 — Paste Domains & Mode: Paste root domains (Unlimited) and choose Create Zone & Fetch NS or Fetch Existing Nameservers Only.
  4. Step 4 — Export NS List: Click Run Zone Provisioner, then click Export Tab CSV to get the domain-to-nameserver mapping.

Step-by-Step Guide • 6. DNS Auditor & Backup

Purpose: Read and verify active Cloudflare DNS records across unlimited domains and download a full CSV snapshot for backup or troubleshooting.

  1. Step 1 — Cloudflare Token: Select a saved Cloudflare account with Zone:Read and DNS:Read permissions.
  2. Step 2 — Paste Domains & Filter: Enter domains (Unlimited) and pick ALL Record Types or filter by TXT, MX, CNAME, or A.
  3. Step 3 — Audit & Export Backup: Click Audit Live DNS Records to inspect live records and proxy flags (P), then click Export Tab CSV.

Step-by-Step Guide • 7. Dynadot → Cloudflare Migration

Purpose: Automatically add Dynadot domains into Cloudflare, update Dynadot nameservers to Cloudflare's assigned NS pair, configure SSL/HTTPS, and create initial DNS records.

  1. Step 1 — Cloudflare & Dynadot Keys: Select your Cloudflare token above, enter/save your Dynadot API v3 Key (whitelist your server IP in Dynadot API settings), and click Load Accounts.

  3. Step 3 — Execute Sync: Click Sync Dynadot → Cloudflare to create zones, push NS records to Dynadot, and trigger activation checks.

Step-by-Step Guide • 11. Amazon SES Verification & Cleanup

Purpose: Bulk-enroll domains in Amazon SES v2 with Easy DKIM, MAIL FROM, SPF, and DMARC in Cloudflare, check verification status, or bulk-delete domains from SES (with optional Cloudflare SES DNS cleanup).

  1. Step 1 — Credentials & Region: Select your Cloudflare token above, enter/save your AWS IAM keys with AmazonSESFullAccess, and pick the SES region.
  2. Step 2 — Choose Mode: Select Enroll in SES + Add CF DNS + Verify, Check Existing SES Status Only, or Delete Domains from SES.

📘 13. Visual API Key, Token & Session Creation Guide Book

Light, high-contrast symbol-guided setup manual for all 6 integrations used across Tabs 1–14.

🌐 Portal 🛡️ Permissions 🔑 Generate Key ⚠️ Critical Rule 💾 Save in App
☁️ 1. Cloudflare User API Token
Tabs 1–11
🌐 Step 1 Log in to dash.cloudflare.com → click Profile Icon (top-right) → My Profile → API Tokens.
🔑 Step 2 Click Create Token → scroll to Create Custom Token → Get started.
🛡️ Step 3
Assign these exact Permissions:
✓ Account Settings → Read ✓ Zone → Read & Edit ✓ Zone DNS → Edit ✓ Zone Settings → Edit ✓ Page Rules → Edit ✓ Cache Purge → Purge
⚠️ Step 4 Set Account Resources = Include → All accounts and Zone Resources = Include → All zones.
💾 Step 5 Click Continue to summary → Create Token, copy it, paste into the top Cloudflare Account & Token bar, and click Save Account.
🔄 2. Dynadot API v3 Key & IP Whitelist
Tab 7
🌐 Step 1 Log in to dynadot.com → open Tools → API in the left sidebar.
🔑 Step 2 Set API Access = Enabled and copy your API v3 Production Key.
⚠️ Step 3 Mandatory IP Whitelist: Paste your local PC IPv4 (if running locally) and Render outbound static IPs (if hosted on Render) into Allowed IP Addresses and click Save Settings.
💾 Step 4 Open Tab 7 (Dynadot → CF), enter a label + API v3 Key under Saved Dynadot Account, and click Save.
📨 3. AWS IAM Keys for Amazon SES v2
Tab 11 (36 Regions)
🌐 Step 1 Open AWS Management Console → IAM → Users → Create user (e.g., occ-ses-bot).
🛡️ Step 2 Select Attach policies directly → check AmazonSESFullAccess → click Create user.
🔑 Step 3 Open the user → Security credentials → Create access key → select Application running outside AWS.
💾 Step 4 Copy Access Key ID (AKIA...) + Secret Access Key, paste in Tab 11, pick any of the 36 AWS SES regions, and click Save.
🌐 4. AWS IAM Keys for Amazon S3 Static Hosting
Tab 8 (36 Regions)
🌐 Step 1 Open AWS Console → IAM → Users (reuse your IAM user or create occ-s3-host).
🛡️ Step 2 Under Permissions → Add permissions, attach AmazonS3FullAccess.
🔑 Step 3 Generate an Access Key ID & Secret Access Key under Security credentials.
💾 Step 4 Paste both keys in Tab 8 (AWS S3 & CDN), choose your AWS Region, and click Save.
✉️ 5. Google Postmaster & Site Verification OAuth2
Tab 9 (ya29...)
🌐 Step 1 In console.cloud.google.com, enable Gmail Postmaster Tools API & Google Site Verification API and create a Web OAuth Client ID with redirect https://developers.google.com/oauthplayground.
🛡️ Step 2
Open developers.google.com/oauthplayground → Gear icon → enter Client ID & Secret → authorize these 2 scopes:
https://www.googleapis.com/auth/postmaster.readonly https://www.googleapis.com/auth/siteverification
🔑 Step 3 Click Authorize APIs → Exchange authorization code for tokens and copy the ya29... Access Token.
💾 Step 4 Paste into Tab 9, click Check Token Expiry, and click Save.
🇾 6. Yahoo Sender Hub Session Cookie
Tab 10
🌐 Step 1 Log in to senders.yahooinc.com in Chrome and press F12 (DevTools) → Network tab.
🛡️ Step 2 Filter by Fetch/XHR, refresh the page, and click any request to senders.yahooinc.com.
🔑 Step 3 Scroll to Request Headers and copy the full Cookie: string.
💾 Step 4 Paste into Tab 10, click Save, then click Fetch Unverified from Yahoo.
